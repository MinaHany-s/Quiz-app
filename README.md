# Quiz App

A simple and interactive quiz application built with React, TypeScript, and Tailwind CSS.

## Live Demo

[Try the Quiz App](https://quiz-app-phi-one.vercel.app/)

## Features

- Choose the number of questions.
- Select a quiz category.
- Choose difficulty: Easy, Medium, or Hard.
- Fetch multiple-choice questions from the Open Trivia DB API.
- Get instant feedback on your answers.
- View your final score and results.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Open Trivia DB API

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/MinaHany-s/Quiz-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Quiz-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## API

This project uses the [Open Trivia DB API](https://opentdb.com/) to fetch quiz questions.
